# Babyshop — маркетплейс для аптек (Telegram Mini App)

## Что внутри
- `backend/` — сервер (Node.js/Express), база данных SQLite, Telegram-бот
- `webapp/` — Mini App (каталог, корзина, заказы, профиль)
- `admin/` — админ-панель управления товарами

## Шаг 1. Установи Node.js
Если ещё не установлен — скачай с https://nodejs.org (версия LTS, "рекомендуемая").

## Шаг 2. Настрой .env
1. В папке `backend/` скопируй файл `.env.example` и переименуй копию в `.env`
2. Открой `.env` и заполни:
   - `BOT_TOKEN` — токен от BotFather (уже есть)
   - `WEBAPP_URL` — заполнишь после деплоя (шаг 4)
   - `OWNER_TELEGRAM_ID` и `BROTHER_TELEGRAM_ID` — напиши боту **@userinfobot** в Telegram, он пришлёт твой ID; попроси то же самое сделать брата
   - `ADMIN_LOGIN` и `ADMIN_PASSWORD` — придумай логин и длинный пароль для входа в админку
   - `ADMIN_SECRET_TOKEN` — сгенерируй командой ниже

Генерация токена:
```
cd backend
node generate_admin_secret.js
```
Скопируй результат в `.env` в поле `ADMIN_SECRET_TOKEN`.

## Шаг 3. Установи зависимости и проверь локально
```
cd backend
npm install
npm start
```
Если всё правильно — увидишь `Babyshop backend running on port 3000` и `Babyshop bot started...`

## Шаг 4. Разверни на хостинге (чтобы было доступно всегда, а не только на твоём компьютере)

Рекомендую **Railway** (railway.app) — бесплатный старт, простая загрузка проекта:
1. Зарегистрируйся на railway.app через GitHub
2. Создай новый проект → "Deploy from GitHub repo" (или "Empty project" + загрузка файлов)
3. Залей туда содержимое папки `backend/` (плюс папки `webapp/` и `admin/` рядом, они используются сервером)
4. В настройках проекта на Railway добавь все переменные из твоего `.env` (Railway → Variables)
5. После деплоя Railway даст тебе публичный адрес вида `https://babyshop-production.up.railway.app`
6. Вставь этот адрес + `/webapp` в переменную `WEBAPP_URL` (например `https://babyshop-production.up.railway.app/webapp`)
7. Перезапусти проект на Railway, чтобы применились новые переменные

## Шаг 5. Проверка
1. Открой бота `t.me/babyshop004_uz_bot`, нажми `/start`
2. Должна появиться кнопка "Открыть каталог" — нажми
3. Внутри должен открыться каталог с товарами
4. Попробуй зарегистрироваться, добавить товар в корзину, оформить заказ
5. Проверь, что уведомление о заказе пришло тебе и брату в Telegram

## Админ-панель
Открой `https://твой-домен/admin` в браузере (на компьютере или телефоне), войди с логином/паролем из `.env`. Там можно добавлять/редактировать/удалять товары.
